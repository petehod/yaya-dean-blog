# Blog Yaya Dean



## Overview

Welcome to Yaya Dean – a custom MDX and React Next.js blog crafted as a creative hub for writing guitar melodies. This project is my playground where I apply the lessons from Josh Comeau’s Joy of React course, mixing modern tech with my passion for guitar melodies. It’s designed for music producers and guitarists who want to up their melody game.

![Logo](./public/blog.png)

###  Why Yaya Dean?
	•	Custom MDX Experience: Write and share content with complete control, like crafting your own musical score.
	•	Modern Stack: Built with React and Next.js for a smooth, high-performance experience.
	•	Inspired & Passionate: Born out of a love for guitar melodies and a desire to share insights that truly resonate.

###  Features
	•	Fully Customizable: Leverage a custom MDX setup to create rich, engaging content.
	•	Professional Yet Fun: A unique blend of a professional look with a playful, musical spirit.

## Getting Started

### Installation
To get started with **Yaya Dean**, follow these steps:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/petehod/yaya-dean-blog.git
   cd yaya-dean-blog
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Start Development server:**
   ```bash
    npm run dev
   ```
4. Visit [localhost:3001](localhost:3001) to see the blog in action!
